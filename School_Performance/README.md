# School Student Performance Analysis Dashboard 📚

A Tableau-based dashboard project aimed at analyzing academic performance trends across schools, grades, and regions to provide actionable insights for education stakeholders.

---

## 📌 Objective
To identify patterns in student performance across different grades and locations using interactive dashboards. The analysis helps in highlighting:
- Top-performing grades or districts
- Subjects where students are excelling or struggling
- Gender-based academic trends

---

## 📊 Dashboard Features
- **Heatmap** to visualize grade-wise performance across districts
- **Filters** for Year, Gender, and Subject
- **KPI Cards** for average scores, pass percentage, etc.
- **Bar Charts** comparing grades and school types

---

- Tableau Public
- Excel/CSV (as data source)
