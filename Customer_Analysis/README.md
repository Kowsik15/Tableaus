# 🛍️ Retail Business Sales Performance Dashboard

This Tableau project provides a detailed sales performance analysis for a retail business. The dashboard enables stakeholders to explore trends in revenue, profit, and customer behavior across regions, categories, and time periods.

---

## 🎯 Objective

To design an interactive Tableau dashboard that allows users to:
- Monitor **monthly and quarterly sales trends**
- Compare **product category** and **segment-level** performance
- Identify high-profit regions and customer segments
- Make informed business decisions using visual data storytelling

---

## 📊 Dashboard Features

- 📈 **Line Graphs**: Monthly & Quarterly sales trends  
- 📊 **Bar Charts**: Profit by Product Category and Segment  
- 🌍 **Geo Map**: Regional sales and profit contribution  
- 🧮 **KPIs**: Total Sales, Profit, Quantity, and Order Count  
- 🔍 **Interactive Filters**: Region, Segment, Category, Date

---

## 🛠️ Tools & Technologies

- **Tableau Public**
- Sample Superstore Dataset (CSV format)

---

## 📁 Dataset Overview

- **Fields Used**:
  - `Order Date`, `Sales`, `Profit`, `Quantity`, `Category`, `Sub-Category`, `Region`, `Segment`, `Customer ID`

- **Source**: Tableau's Sample Superstore Dataset

---

## 🔍 Key Insights

- The **West Region** generated the highest revenue over the year  
- **Office Supplies** had high profit margins despite lower sales  
- The **Corporate segment** yielded the highest average order value  
- Sales dipped in Q2, indicating a potential seasonal or logistic issue
